# Data Analytics Portfolio Projects 

This repository contains **5 complete, portfolio-ready Data Analytics projects**.

Each project follows a clear structure with:

- **Objective**
- **Tools Used**
- **Key Analysis**

All projects use different datasets and demonstrate end-to-end skills in **SQL + Excel + Python + Power BI**.

## How to Use
1. Open any project folder / markdown file.
2. Follow the Objective, Tools Used, and Key Analysis sections.
3. Download the recommended public dataset.
4. Build the analysis using the suggested steps.
5. Create the Power BI dashboard as described.
